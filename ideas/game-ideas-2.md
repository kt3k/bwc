# ゲームを面白くするアイデア集 (第2弾)

第1弾 (game-ideas.md) の14アイデアは実装済み。ここでは実装済みメカニクス (コイン
/ チェイサー / ジャンプ台 / 看板 / 宝箱 / 氷 / りんごゲート / 効果音 / セーブ /
ミニマップ / 植樹 / 昼夜 / 釣り / 転がる岩 / チュートリアルコース)
を土台に、新しいギミックと「ギミックの組み合わせで生まれるパズル」を考える。

対応する拡張ポイント: CollectDelegate (item.ts) / PushedDelegate・onEnter・
growth (prop.ts) / IdleDelegate・ActorPushedDelegate・buff (actor.ts) / cell
フラグ (catalog.ts: slippery, water) / signals / IField.spawn* /
tools/generate_map_blocks.ts のテーマ生成。

## A. 新ギミック案

### A-1. 圧力スイッチ + 連動ドア

踏むと離れた場所のドアが開くスイッチ。ソーコバン式パズルの核になる。

- prop `plate` (canEnter: true, `onEnter: "plate"`, dataSchema:
  `{ group: string }`) と prop `door` (canEnter: false, 同じ `group`)
- 踏まれている間だけ同 group の door を `props.remove` / 離れると復活。
  「押し続ける係」が必要になるのがポイント
- 現状 onEnter は main のみ発火 (MoveEndMainActor)。**NPC や岩がスイッチを
  踏めるようにする**と一気にパズルが広がる: FieldActors.step で全 actor の
  移動完了セルを prop に通知する拡張が必要
- 岩をスイッチの上に転がして止めれば「重しで開けっぱなし」が成立する

### A-2. ベルト床 (一方通行)

乗ると指定方向に強制スライドする床。氷の亜種。

- cell フラグ `conveyor?: "up" | "down" | "left" | "right"` を追加
- Actor.step の氷処理 (isSlippery) と同じ場所で、方向だけ固定で slide を
  unshift。入口の向きに関係なく流されるので一方通行路が作れる
- 逆走不能な通路、ベルトの乗り換えタイミングパズル、氷との連結

### A-3. コインショップ

コインの使い道を作る。経済ループの完成。

- prop `shop` (`pushed: "shop"`, dataSchema: `{ sells: string, price: number }`)
- 押すと coinCount >= price なら減算して `field.spawnItem(sells, ...)` を
  足元に落とす。足りなければトースト "NEED n COINS"
- 村ブロックに配置。種・きのこ・りんごを売る。釣り/宝箱/敵潰しで稼ぐ動機付け

### A-4. 鍵アイテムと鍵ゲート

りんごゲートの汎用化。「消費する鍵」で開くゲート。

- item `key` (collect: "key" → keyCount signal)、prop `key-gate`
  (`pushed: "key-gate"`) は開くときに keyCount を1消費する
- りんごゲートと違い**消費型**なので、どのゲートに使うか選択が生まれる
- 鍵3個・ゲート5箇所の宝物庫、のような取捨選択パズル

### A-5. 時限ゲート & ダッシュ回廊

一定時間だけ開くゲート。スピード系アイテムの使い所を作る。

- prop `timer-gate` (`pushed: "timer-gate"`, dataSchema:
  `{ duration: number }`): 押すと duration フレームだけ vanish して canEnter
  化、経過後復活 (growth の interval 処理を流用できる)
- 遠くのゲートまでの長い回廊: 素のスピードでは間に合わず、きのこ (2x) や
  紫きのこ (4x 直進) を拾ってから押す設計にする
- チュートリアル卒業後の最初の応用問題に良い

### A-6. ゴースト (夜限定の敵)

夜だけ現れる敵で昼夜サイクルに意味を足す。

- actor `ghost` (`idle: "ghost"`): nightDarkness > 0.3 のときだけ活動し、
  壁をすり抜けて (canEnter 無視で) ゆっくり追跡。昼は不可視+停止 (image()
  で透明を返す)
- 接触でコインを1枚盗む。倒せないが、ランタンの光の中 (半径内) には 入ってこない
  → ランタンからランタンへ渡り歩く夜の移動
- 夜の間だけレアアイテム (青りんご?) が湧く、とセットでリスク/リワード

### A-7. 点灯式ランタン

ランタンを「点ける」行為でプレイヤーが安全地帯を作る。

- prop `lantern-unlit` (`pushed: "light-lantern"`): 押すと `lantern` に 差し替え
  (spawn を置き換え)、以後夜に光る
- 点灯状態は座標キーの Map (growth states と同じ方式) で永続化
- 「夜の道を自分で開通させる」進行が作れる。A-6 のゴーストと相性が良い

### A-8. 魚の納品クエスト

フォロワー機構 (fish) に目的地を与える。

- prop `fish-shrine` (`pushed: "fish-shrine"`): フォロワーに fish がいれば
  受け取ってコイン×5に変換。いなければ "BRING ME A FISH"
- フォロワーは space (ジャンプ) で解除される仕様なので、**ジャンプ台や
  クレート破壊 (押す=バウンス) を避けて運ぶ**ルート選びが自然にパズルになる
- 複数匹連結 (フォロワーチェーン) でボーナス

### A-9. 埋蔵金と宝の地図

看板とミニマップを「読む」動機を作る。

- 看板に座標ヒント (`"DIG AT (-350, 120)"`) を書く
- 目印セル (ひび割れ床 cell `x`) の上で space → `field.spawnItem` で
  財宝が飛び出す。IdleMainActor の space 分岐に「足元が `x` なら掘る」を追加
- ミニマップと照らし合わせて探す。地図ヒントは宝箱から出る紙アイテムでも良い

### A-10. タイムアタックリング

コースを既に持っているので計測系はすぐ作れる。

- prop `race-start` / `race-goal` (onEnter): start を踏むと field.time を
  記録、goal で差分をトーストに表示。既定タイム以下ならコイン報酬
- 氷・ベルト床・ジャンプ台を織り交ぜた専用コースをブロック1つに用意
- ベストタイムをセーブ (save.ts に1キー追加)

## B. ギミック組み合わせパズル案

単体ギミックを「制約」として掛け合わせ、部屋単位のパズルを作る。 生成は
generate_map_blocks.ts にパズル部屋ビルダーを足して行う
(チュートリアルコースと同じ protected rect 方式で外周を密閉する)。

### B-1. 氷上の岩ソーコバン 【岩 × 氷 × 水】

- 岩は押すと障害物まで直進する。氷の上では狙った位置に止められない —
  そこで**水路に落として橋にする** (要拡張: 岩が水セルに接したら岩を消して
  セルを floor に差し替える。FieldBlock.updateCell + renderChunk 再描画)
- 部屋: 氷原の中に水路が走り、対岸に宝箱。岩は3個、正しい順で正しい列に
  落とさないと橋が繋がらない。失敗してもリセットポータルならぬ
  「岩リスポーンスイッチ」(A-1 の plate で岩 spawn) で再挑戦可能にする

### B-2. スプリング・ピンボール 【ジャンプ台 × 氷 × 壁】

- ジャンプ台は「進行方向に3セル飛ばす」= **入る向きがすべて**
- 氷に囲まれた盤面にジャンプ台を点在させ、正しい順で正しい向きから
  乗り継がないと中央の島に届かない。誤ると氷で入口まで滑り戻される
- 実装済みメカニクスだけで作れる (台の着地点を次の台/氷レーンに合わせて
  配置するだけ)。まず1部屋試作する価値あり

### B-3. チェイサー誘導アリーナ 【チェイサー × 岩 × 氷レーン】

- チェイサーはプレイヤーを追う = **プレイヤーが動きをコントロールできる敵**
- 岩レーンの延長線上にチェイサーを誘い込み、岩を押して潰す (現状の
  メカニクスで既に成立: 岩は進路上の NPC を潰してコインを落とす)
- 部屋: りんごを持って入ると3体のチェイサーが寄ってくる。全部潰すと 奥のゲートへ
  (A-1 の「チェイサー全滅で開くドア」があるとなお良い)
- りんごを持つほど敵が寄る=りんご所持数がリスクという駆け引き

### B-4. 植樹ストッパー 【種 × 岩 × 氷】

- 苗/木は canEnter: false = **プレイヤーが任意の位置に作れる唯一の障害物**
- 氷上を直進する岩は木の手前で止まる → 種を植えて岩の停止位置を設計し、
  岩を足場・重し (A-1)・チェイサー避けの壁として配置する
- 部屋: 広い氷原の指定セル (ひび割れ床) の上に岩を止めれば橋が開通。
  種は3個だけ支給、植える位置の逆算パズル
- 現状でも「木で岩が止まる」は成立済み。成長を待つ時間も戦略になる

### B-5. 夜のランタン回廊 【昼夜 × ランタン × ゴースト × りんご】

- 夜はチェイサーの索敵2倍 + ゴースト (A-6) 徘徊。しかし夜にしか開かない
  「月光ゲート」(nightDarkness > 0.5 のときだけ vanish する prop) の先に報酬
- 未点灯ランタン (A-7) を昼のうちに点けて安全な足場を作っておき、
  夜が来たら光を伝って月光ゲートへ走る — 昼=準備 / 夜=実行 の2フェーズ制
- 時間管理 (5分サイクル) を初めてプレイヤーに意識させるコンテンツ

### B-6. 魚の護送 【釣り × フォロワー × ジャンプ台 × クレート】

- A-8 の納品クエストを立体化: 釣り場から祠までの道に**ジャンプ台が
  敷き詰められた近道**と、**クレートを壊さないと通れない遠回り**を用意
- ジャンプ台を踏むと jump でフォロワーが外れる → 近道は魚を失う罠。
  クレートを押すのはバウンス (jump ではない) なのでフォロワー維持可能、
  という仕様理解を問う
- 「什器の仕様がそのまま謎になる」低コスト高効率パズル

### B-7. 一方通行迷路 【ベルト床 × 氷 × スプリング】

- A-2 のベルト床で「入れるが戻れない」部屋を連結した迷路。誤入場のリカバリは
  リセットではなく**周回ルート**で解決させる (袋小路を作らない)
- 氷は「直進のみ」、ベルトは「強制方向」、スプリングは「3セル飛び」 —
  3種の移動制約の混成で、盤面を見て脳内シミュレーションする楽しさを出す
- 治安装置: 迷路内は敵なし・報酬はコイン。純粋パズルエリアとして分離

### B-8. 宝物庫強盗 (総合問題) 【全部盛り】

- 大型ブロック1つを「巨大宝物庫」にする: 入口はりんごゲート、内部は
  圧力スイッチ式の扉 (岩の重し)、氷の金庫室 (B-2 のピンボール)、
  夜だけ開く月光区画 (B-5)、最深部に鍵ゲート×1 (鍵は B-1〜B-3 の 各パズルの報酬)
- 各部屋が1ギミック合成に対応し、全部解くと「大金貨」(コイン+50) と
  実績看板。第2のエンドコンテンツ
- チュートリアルコースが「基本操作の卒業試験」なら、こちらは
  「ギミック理解の卒業試験」

## C. 実装優先度メモ

| 優先 | アイデア                     | 理由                                    |
| ---- | ---------------------------- | --------------------------------------- |
| 高   | B-2 スプリング・ピンボール   | 追加実装ゼロ。マップ生成だけで試せる    |
| 高   | B-3 チェイサー誘導アリーナ   | 追加実装ほぼゼロ。岩の潰し既存          |
| 高   | A-3 コインショップ           | コインの使い道が現状ないため            |
| 中   | A-1 圧力スイッチ             | パズルの核。NPC/岩の onEnter 拡張が必要 |
| 中   | B-4 植樹ストッパー           | 種の戦略的用途。ほぼ成立済み            |
| 中   | A-6 / A-7 / B-5 夜コンテンツ | 昼夜サイクルの活用                      |
| 低   | A-2 ベルト床 / B-7 迷路      | 新 cell 追加。効果は大きいが後回し可    |
| 低   | B-1 岩の橋                   | セル書き換え+再描画の拡張が重め         |
| 低   | B-8 宝物庫強盗               | 他が揃ってから作る総合問題              |

設計原則: 新ギミックは「単体で楽しい」より「**既存ギミックと直交する制約**」
を優先する (氷=直進 / ベルト=強制方向 / 台=向き依存 / 木=任意障害物 /
岩=直進する重し / 敵=誘導可能な移動体)。直交する制約が増えるほど、
組み合わせパズルの空間は掛け算で広がる。
