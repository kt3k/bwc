# 有限群で動くパズル (DEBUG マップの GROUPS)

kt3k/group のスイッチの考え方をそのまま仕掛けにする: 「状態 g でボタン x
を押すと g·x に移る。だから e から始めれば、状態はいつも押したボタンの積」。
ここでは状態は **石の並び**、ボタンは **レバー**。

置き場所: DEBUG マップ (block_10000.-10000) の右側、ほかと壁で隔てた GROUPS
の区画。DEBUG マップ上の行の `GROUPS` と地面に書いたポータル (DEBUG の
到着点の右) か、START の島のデバッグポータルの広間の `GROUPS` から入る。直接なら
`http://localhost:8000/#10109,-9995`。
区画の入口に、区画のパズルだけをやり直せる RESET (`goal-reset`, prefix
`groups-`) がある。作るのは tools/generate_debug_map.ts
(`deno task generate-debug`)、絵は tools/draw_groups.ts。

## 部品 (新しいプロップは 6 つ、ルールは 1 行ずつ)

| プロップ      | ルール                                                                                       |
| ------------- | -------------------------------------------------------------------------------------------- |
| `group-lever` | ぶつかると (自分・見張り・転がる岩)、結ばれた石を決まった通りに入れ替える/回す               |
|               | `over: true` は地面に平たく埋まったレバー: 上を転がる物が引く (プレイヤーが踏んでも動かない) |
| `group-stone` | 立石。自分の場所にいま居る石の模様を見せる (輪・十字・横縞・渦・三角・菱形)                  |
| `group-moai`  | モアイ。向き 4 × 鏡 2 = 8 姿勢。右耳の白い輪で鏡像かどうかが分かる                           |
| `group-mural` | 壁画: 目標の模様/姿勢 (上から見た頭: 鼻が向き、輪が右耳)。`id` 付きは叩く札 (仲間外れ探し)   |
| `group-door`  | 並びが目標になった最初の 1 回で開き、開いたまま (セーブ)。ゴールの演出と読めない文字         |
| `group-bell`  | 並びが最初 (e) に戻るたびに鳴る。`need` のレバーを全部使って戻した最初の 1 回がゴール        |

データの形 (model/group.ts): 並び `arrangement[place] = token`、最初は恒等。
レバーの `cycles` は「物の行き先」: `[[0, 1, 2]]` は 0 の物を 1 へ、1 を 2 へ、
2 を 0 へ。場所の置換として合成すると g → g·x で、kt3k/group のスイッチと
同じ。モアイは「4 つの面 (後・左・顔・右) が 4 つの方角 (上・右・下・左) に
乗った並び」として同じ仕組みで扱う: 回すレバーは 4 サイクル `[[0,1,2,3]]`、
鏡のレバーは左右の入れ替え `[[1,3]]`。

並びはメモリだけ (再読み込みで e に戻る)。開いた扉とゴールは
`group.<id>`、文字は `group.<id>.reward` として集めた ID に入り、セーブに残る。
`isGroupKey` は model/goal.ts の DONE_KEYS に入れた: DEBUG の他のゴール
(debug-bell など) も数えられているのと揃え、RESET で消せる (goal-reset の
GOAL_KINDS に `group`) ので、遊びなおしても数が積み上がらない。WILDS には
置かない。

## 8 つのパズル

各ベイの下に、ルールの看板と、デバッグ用の看板 (群と解) がある。

| #  | ベイ (群 id)            | 群                | 作り                                                                                                                        | 解                                             |
| -- | ----------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 1  | 三つの立石 (`s3`)       | S₃                | 立石 3、レバー 2 (左の組・右の組を入れ替え)。目標は「左→右」で、「右→左」とは違う                                           | 左, 右                                         |
| 2  | 四つの立石 (`s4`)       | S₄                | 立石 4、隣同士を入れ替えるレバー 3。目標は逆順                                                                              | 1 2 3 1 2 1 (6 回)                             |
| 3a | 回るモアイ (`z4`)       | Z₄                | モアイ + 回すレバー                                                                                                         | 回す ×2 (後ろ向き)                             |
| 3b | 回って映るモアイ (`d4`) | D₄                | + 鏡のレバー。r⁴ = s² = e, srs = r⁻¹                                                                                        | 鏡, 回す (回す, 鏡だと右を向く)                |
| 4  | 同じ 4 状態の 2 部屋    | Z₄ と Z₂×Z₂       | 2×2 の石。左は 1 本のダイヤル (四角をひと回り)、右は独立した 2 本のトグル (左右・上下)                                      | ダイヤル ×2 / トグル 2 本 (順不同)             |
| 5  | 見張りの時計 (`clock`)  | S₃ (時計は位数 2) | 見張りが通路の両端のレバー a (左の組) を交互に引く。自分のレバー b (右の組) を引く時刻で結果が変わる                        | 左の組が入れ替わっている間に b、1 拍待つ (aba) |
| 6  | 岩の言葉 (`words`)      | S₃ の語           | 3 本のレーンに岩。平たいレバーを転がる順に引く: 上 ab、中 ba、下 b。どのレーンをどの順で転がすか                            | 下→上、または 中→下 (bab)                      |
| 7  | 恒等の鐘 (`bell`)       | S₃ の位数         | 入れ替え (位数 2) と 3 サイクル (位数 3)。並びが戻るたび鐘が鳴る。両方使って戻すとゴール                                    | 入, 回, 入, 回 ((sc)² = e)                     |
| 8  | 仲間外れの群 (`odd-*`)  | S₃ ≅ D₃ と Z₆     | 見た目の違う 3 部屋: 一列の 2 つの入れ替え (S₃)、三角の回転と裏返し (D₃)、6 つの輪とダイヤル (Z₆)。仲間外れの部屋の札を叩く | Z₆ の札 (可換で、位数 6 の元がある)            |

### 決めたこと

- **5 の時計**: 扉は毎フレーム並びを見るので、可換な群では「いつ引くか」は
  結果を変えられない (状態はいつも a^k b^m)。だから時計 (見張りが a と a⁻¹
  を交互に引く、位数 2) を非可換な S₃ の中に置いた。b を e で引けば {b, ba}
  の間を、a で引けば {ab, aba} の間を行き来する: 目標 aba は後者だけ。1 拍は
  およそ 1 秒 (原則 5: 待ちは 3 秒以内)。
- **6 の岩**: 岩は止まるまで転がるので、止まらない (上を転がれる) レバーが
  要る。それが `over` の平たいレバー。岩は 1 個ずつで、失敗したら RESET。
- **7 の鐘**: 扉なし。鐘はいつでも e で鳴る (デモ) が、ゴールは「両方の
  レバーを使って e に戻した」とき。ss や ccc では数えない。最短は (sc)²。
- **8**: 札は壁画プロップの `id` 付き。仲間外れでない札は「NOT THIS ONE」と
  言うだけ。

## ケイリーの部屋 (CAYLEY、1 マス 2 状態で全部の群)

上の 8 つは 1 マスに状態が多い (6 模様の立石、8 姿勢のモアイ)。そこで **1
マスはできるだけ少ない状態 (開いている/閉じている) にして、マスを
必要なだけ使う** 形で、位数 1〜20 の群を全部 (54 個) 並べた。表し方の ほかの案は
docs/group-representations.md。

置き場所: DEBUG の右隣の 2 ブロック (block_10200.-10000 と、その下の
block_10200.-9800、地続き)。GROUPS の区画の上の行の `CAYLEY`
と地面に書いたポータルか、START の島の `CAYLEY` から入る (直接なら
`http://localhost:8000/#10202,-9996`)。到着点の横に戻りの PORTAL と RESET
(`goal-reset`, prefix `cayley-`)。作るのは tools/generate_cayley_map.ts
(`deno task generate-debug` が一緒に書く)、並べ方は tools/cayley_rooms.ts、 絵は
tools/draw_cayley.ts。群の表は kt3k/group の data.json の写し
(model/cayley-groups.ts、tools/make_cayley_groups.ts が書く)。

### 部品 (新しいプロップは 2 つ)

| プロップ       | 状態                     | ルール                                                                                    |
| -------------- | ------------------------ | ----------------------------------------------------------------------------------------- |
| `cayley-gate`  | 開く / 閉じる            | 元 1 つにつき 1 つ。部屋の元が自分のときだけ開く。だから開いている門はいつもちょうど 1 つ |
| `cayley-lever` | 引くたび柄が左右に倒れる | 生成元 x 1 つにつき 1 本。開いている門を g から g·x へ動かす (右から掛ける)               |

- データ: 門は `{room, group, el, alcove}`、レバーは `{room, group, by}` (by
  が生成元)。部屋の表は群のキー (`"8.3"` = GAP の (8,3)) で引く
  (model/cayley.ts)。部屋の元はメモリだけ (再読み込みで e)。
- 門の奥は 1 マスの小部屋。まぐさ石の印: 輪は e の門 (始まり)、菱形は
  目標の門。目標の門がはじめて開くとゴール (`cayley.<id>`、セーブに残る)、
  演出と読めない文字 (`cayley.<id>.reward`) がその小部屋に出る。
- 門は誰かが門や小部屋に立っている間は閉まらない (壁と同じく待つ)。
- レバーの見た目は GROUPS のレバーの絵を借りた: 位数 2 の生成元は鏡の
  彫り、それ以外は回転の彫り。上に白い文字 A B C D。
- 目標: レバーだけで (逆元なしで) 4 回 (届く最遠がそれより近ければそこ)
  の元。非可換な群では、最短の語を逆順に引くと別の門が開くものを選ぶ
  (順番が効く)。デバッグ看板に解と「逆順だと別の門」。
- ゴールに数える: GROUPS のパズルと同じく DONE_KEYS に `isCayleyKey` を 入れた
  (DEBUG の他のゴールも数えている)。RESET (goal-reset の GOAL_KINDS に `cayley`)
  で消せるので、遊び直しても数は積み上がらない。

を引いて回る門たち) を輪にして描く。

## 灯の格子 (LAMPS、置換行列)

docs/group-representations.md の案 1。置換群の元を **置換行列** として 見せる:
n×n の床の灯 (`lamp-cell`)、行 i が物 i、列 j が場所 j で、(i, j)
が点いているのは「物 i が場所 j にある」とき。だから **各行・各列に ちょうど 1
つ点いている** (はじめは対角線、e)。灯は点いている/消えている の 2 状態だけ。

置き場所: GOALS の右隣の block_10600.-10000。START の島のデバッグ
ポータルの広間の `LAMPS` から入る (直接なら
`http://localhost:8000/#10602,-9996`)。 到着点の横に戻りの PORTAL (地面に START)
と RESET (`goal-reset`, prefix `lamps-`)。作るのは tools/generate_lamp_map.ts
(`deno task generate-debug` が一緒に書く)、部屋と目標は
tools/lamp_rooms.ts、絵は tools/draw_lamps.ts。

### 部品 (新しいプロップは 2 つ)

| プロップ      | 状態          | ルール                                                                    |
| ------------- | ------------- | ------------------------------------------------------------------------- |
| `lamp-cell`   | 点く / 消える | 部屋 (`group`) の並びで、自分の行の物が自分の列にあるときだけ点く         |
| `lamp-plaque` | 点く / 消える | 目標の格子の札。データの `lit` のまま変わらない飾り                       |
| `group-lever` | (GROUPS の)   | `cycles` は列 (場所) の巡回: `[[0, 1]]` は列 1 と 2 を入れ替える          |
| `group-door`  | (GROUPS の)   | 灯が札と同じになった最初の 1 回で開き、開いたまま。奥に読めない文字が出る |

- 状態は GROUPS と同じ並び `arrangement[place] = thing` (model/group.ts)。
  レバーは列を動かすだけなので、点いている灯は自分の行から出ない。場所の
  置換として合成すると g → g·x (kt3k/group のスイッチ、右作用)。純粋な 部分は
  model/lamp-grid.ts (点いているか、行列、1 行 1 列に 1 つの確かめ、
  届く並びの全部と最短の語、目標の選び方)、灯は model/lamp-room.ts。
- ゴール: 扉は `group-door` なので、ゴールは `group.<id>` (id は `lamps-s3`
  など)、文字は `group.<id>.reward`。GROUPS と同じく数え (DONE_KEYS の
  `isGroupKey`)、RESET (prefix `lamps-`) で消える。扉の 言葉は `text` で
  `THE LAMPS ARE LIT AS ON THE PLAQUES`。
- 並びはメモリだけ (再読み込みで対角線に戻る)。開いた扉は残る。
