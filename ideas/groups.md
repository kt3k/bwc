# 有限群で動くパズル (DEBUG マップの GROUPS)

kt3k/group のスイッチの考え方をそのまま仕掛けにする: 「状態 g でボタン x
を押すと g·x に移る。だから e から始めれば、状態はいつも押したボタンの積」。
ここでは状態は **石の並び**、ボタンは **レバー**。

置き場所: DEBUG マップ (block_10000.-10000) の右側、ほかと壁で隔てた GROUPS
の区画。DEBUG マップ上の行の `PORTAL: TO THE GROUPS` (DEBUG の 到着点の右)
から入る。直接なら `http://localhost:8000/#10109,-9995`。
区画の入口に、区画のパズルだけをやり直せる RESET (`goal-reset`, prefix
`groups-`) がある。作るのは tools/generate_debug_map.ts
(`deno task generate-debug`)、絵は tools/draw_groups.ts。

## 部品 (新しいプロップは 6 つ、ルールは 1 行ずつ)

| プロップ      | ルール                                                                                       |
| ------------- | -------------------------------------------------------------------------------------------- |
| `group-lever` | ぶつかると (自分・見張り・転がる岩)、結ばれた石を決まった通りに入れ替える/回す               |
|               | `over: true` は地面に平たく埋まったレバー: 上を転がる物が引く (プレイヤーが踏んでも動かない) |
| `group-stone` | 立石。自分の場所にいま居る石の模様を見せる (輪・十字・横縞・渦・三角・菱形)                  |
| `group-moai`  | モアイ。向き 4 × 鏡 2 = 8 姿勢。右耳の白い輪で鏡像かどうかが分かる                           |
| `group-mural` | 壁画: 目標の模様/姿勢 (上から見た頭: 鼻が向き、輪が右耳)。`id` 付きは叩く札 (仲間外れ探し)   |
| `group-door`  | 並びが目標になった最初の 1 回で開き、開いたまま (セーブ)。ゴールの演出と読めない文字         |
| `group-bell`  | 並びが最初 (e) に戻るたびに鳴る。`need` のレバーを全部使って戻した最初の 1 回がゴール        |

データの形 (model/group.ts): 並び `arrangement[place] = token`、最初は恒等。
レバーの `cycles` は「物の行き先」: `[[0, 1, 2]]` は 0 の物を 1 へ、1 を 2 へ、
2 を 0 へ。場所の置換として合成すると g → g·x で、kt3k/group のスイッチと
同じ。モアイは「4 つの面 (後・左・顔・右) が 4 つの方角 (上・右・下・左) に
乗った並び」として同じ仕組みで扱う: 回すレバーは 4 サイクル `[[0,1,2,3]]`、
鏡のレバーは左右の入れ替え `[[1,3]]`。

並びはメモリだけ (再読み込みで e に戻る)。開いた扉とゴールは
`group.<id>`、文字は `group.<id>.reward` として集めた ID に入り、セーブに残る。
`isGroupKey` は model/goal.ts の DONE_KEYS に入れた: DEBUG の他のゴール
(debug-bell など) も数えられているのと揃え、RESET で消せる (goal-reset の
GOAL_KINDS に `group`) ので、遊びなおしても数が積み上がらない。WILDS には
置かない。

## 8 つのパズル

各ベイの下に、ルールの看板と、デバッグ用の看板 (群と解) がある。

| #  | ベイ (群 id)            | 群                | 作り                                                                                                                        | 解                                             |
| -- | ----------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 1  | 三つの立石 (`s3`)       | S₃                | 立石 3、レバー 2 (左の組・右の組を入れ替え)。目標は「左→右」で、「右→左」とは違う                                           | 左, 右                                         |
| 2  | 四つの立石 (`s4`)       | S₄                | 立石 4、隣同士を入れ替えるレバー 3。目標は逆順                                                                              | 1 2 3 1 2 1 (6 回)                             |
| 3a | 回るモアイ (`z4`)       | Z₄                | モアイ + 回すレバー                                                                                                         | 回す ×2 (後ろ向き)                             |
| 3b | 回って映るモアイ (`d4`) | D₄                | + 鏡のレバー。r⁴ = s² = e, srs = r⁻¹                                                                                        | 鏡, 回す (回す, 鏡だと右を向く)                |
| 4  | 同じ 4 状態の 2 部屋    | Z₄ と Z₂×Z₂       | 2×2 の石。左は 1 本のダイヤル (四角をひと回り)、右は独立した 2 本のトグル (左右・上下)                                      | ダイヤル ×2 / トグル 2 本 (順不同)             |
| 5  | 見張りの時計 (`clock`)  | S₃ (時計は位数 2) | 見張りが通路の両端のレバー a (左の組) を交互に引く。自分のレバー b (右の組) を引く時刻で結果が変わる                        | 左の組が入れ替わっている間に b、1 拍待つ (aba) |
| 6  | 岩の言葉 (`words`)      | S₃ の語           | 3 本のレーンに岩。平たいレバーを転がる順に引く: 上 ab、中 ba、下 b。どのレーンをどの順で転がすか                            | 下→上、または 中→下 (bab)                      |
| 7  | 恒等の鐘 (`bell`)       | S₃ の位数         | 入れ替え (位数 2) と 3 サイクル (位数 3)。並びが戻るたび鐘が鳴る。両方使って戻すとゴール                                    | 入, 回, 入, 回 ((sc)² = e)                     |
| 8  | 仲間外れの群 (`odd-*`)  | S₃ ≅ D₃ と Z₆     | 見た目の違う 3 部屋: 一列の 2 つの入れ替え (S₃)、三角の回転と裏返し (D₃)、6 つの輪とダイヤル (Z₆)。仲間外れの部屋の札を叩く | Z₆ の札 (可換で、位数 6 の元がある)            |

### 決めたこと

- **5 の時計**: 扉は毎フレーム並びを見るので、可換な群では「いつ引くか」は
  結果を変えられない (状態はいつも a^k b^m)。だから時計 (見張りが a と a⁻¹
  を交互に引く、位数 2) を非可換な S₃ の中に置いた。b を e で引けば {b, ba}
  の間を、a で引けば {ab, aba} の間を行き来する: 目標 aba は後者だけ。1 拍は
  およそ 1 秒 (原則 5: 待ちは 3 秒以内)。
- **6 の岩**: 岩は止まるまで転がるので、止まらない (上を転がれる) レバーが
  要る。それが `over` の平たいレバー。岩は 1 個ずつで、失敗したら RESET。
- **7 の鐘**: 扉なし。鐘はいつでも e で鳴る (デモ) が、ゴールは「両方の
  レバーを使って e に戻した」とき。ss や ccc では数えない。最短は (sc)²。
- **8**: 札は壁画プロップの `id` 付き。仲間外れでない札は「NOT THIS ONE」と
  言うだけ。

## テスト

- model/group-lever.test.ts: 群の法則 (S₃ の非可換、組みひも関係、S₄ が 24、 D₄
  の r⁴ = s² = e と srs = r⁻¹ と 8 姿勢が全部違う絵、Z₄ と Z₂×Z₂ の位数、 Z₆ と
  D₃ ≅ S₃)、各レバー、扉が目標ちょうどで 1 回だけ開いて残る、
  鐘、札、RESET、見張りが両端のレバーを引く、岩が平たいレバーを順に引く。
- tools/debug_groups.test.ts: 生成した DEBUG マップで、各ベイのレバーが看板の
  群の大きさになる、各扉の目標に届く、見張りと岩の置き場所。
