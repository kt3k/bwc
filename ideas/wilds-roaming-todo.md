# TODO: WILDS を歩き回る理由 (頼まれごと・ご褒美・目的地)

WILDS (14x9 ブロックの島、tools/generate_wilds.ts) を広く歩き回りたくなる
仕組みのうち、「人に頼まれる」「歩いた先のご褒美」「目的地としての特別な場所」
をやることとして並べる。できたものは `[x]` にして、どこで作ったかを書き足す。

## 人に頼まれる (目的地を作る)

- [ ] **お使い**: 村人が「SOUTHPORT の神殿に手紙を届けて」のように頼む。手紙は
      今ある封筒 (envelope) のアイテムで、届けると報酬が出る。街と村、村と村を
      行き来する理由になる
- [ ] **交易**: 村ごとに安い物・高い物が違う (漁師町 SOUTHPORT では魚が安く、
      山の村ではキノコが安い)。遠くへ運ぶほど得をするので、自然と遠出する
- [ ] **迷子**: 子どもや猫がどこかの森で迷っている。見つけて連れて帰ると、
      ついて歩く (今ある「ついてくる」仕組み、IFollower)
- [ ] **道具の出番**: りんご・魚・種 (docs/item-tools.md) の使いどころを島に
      置く。たとえば「チェイサーが居座る橋」「猫が通せんぼする裏道」「岩を止めれば
      開く遺跡」。道具を持って歩く理由になる

## 歩いた先のご褒美

- [ ] **近道を開く**: 一度遠くまで行くと、帰り道を短くする仕掛け (はね板、
      渡し船、ワープの石碑) が使えるようになる。行った所ほど楽に戻れる
- [ ] **石碑ワープ**: 名所ごとに石碑を置き、触れるとそこへのポータルが START の
      部屋に加わる。開くには自分の足でそこまで行く必要がある
- [ ] **強い移動手段**: 島の奥で 4 倍速のキノコの群生地や、氷の上を速く滑る靴を
      見つける。手に入れると移動がもっと気持ちよくなる
- [ ] **宝の格**: 奥へ行くほど良い宝 (金袋、宝石、剣・盾) が出る。今ある宝の価値
      (カタログの `value`) を、道や着地点からの距離で選ぶ

## 目的地としての特別な場所

- [ ] **島の四隅の秘密**: 北の雪原、南の沈んだ遺跡 (SUNKEN RUINS)、東の岬 (EAST
      CAPE)、西の街の地下水道。それぞれに 1 つずつ大きな謎を置く
- [ ] **運河と川を舟で**: SOUTHPORT の運河や島の川を渡し舟で下る。川はどれも
      水源か港から海までつながっている (generate_wilds の「rivers made whole」)
      ので、川下りがそのまま島を縦断する道になる
- [ ] **CAVERN の奥と地上の対応**: 地上の石碑の文字が、洞窟 (CAVERN) の扉の
      答えになっている。地上と地下を行き来させる

## 作るときに守ること

- docs/design-principles.md の原則に合わせる: 説明より先に見せる、看板は仕組みを
  書いて解き方は書かない、失敗は安く
- 見た目は docs/art-guide.md の通り、パレットの色だけ
- 生成で置くものは generate_wilds の検証 (届かない所がない、など) に通す
