# TODO: WILDS を歩き回る理由 (頼まれごと・ご褒美・目的地)

WILDS (14x9 ブロックの島、tools/generate_wilds.ts)
を広く歩き回りたくなる仕組みのうち、「人に頼まれる」「歩いた先のご褒美」「目的地としての特別な場所」をやることとして並べる。できたものは
`[x]`
にして、どこで作ったかを書き足す。番号は項目を指す名前なので、項目を足すときは続きの番号を振り、振り直さない。

## 人に頼まれる (目的地を作る)

- [x] **1. お使い**: 村人が「SOUTHPORT
      の神殿に手紙を届けて」のように頼む。手紙は今ある封筒 (envelope)
      のアイテムで、届けると報酬が出る。街と村、村と村を行き来する理由になる
      (作った: 村 10 か所の広場と 2 つの街の門の外にポストと郵便屋。ポストに
      ぶつかると別の町あての手紙を渡され、届けると距離に応じたコインと次の手紙。
      運んでいる手紙は画面左下に出て、セーブにも残る。model/errand.ts、
      tools/draw_post_box.ts、generate_wilds の「the post」)
- [x] **2. 交易**: 村ごとに安い物・高い物が違う (漁師町 SOUTHPORT
      では魚が安く、山の村ではキノコが安い)。遠くへ運ぶほど得をするので、自然と遠出する
      (作った: 12 の町それぞれに交易の屋台と商人。町の産物 (SOUTHPORT の魚、
      STONEGATE の鉄、HIGHCROFT のキノコなど) を 1 箱 5 コインで売り、ほかの町は
      産地からの距離に応じた値で買い取る。持てる箱は 1 つで、画面左下に出て
      セーブにも残る。model/trade.ts、tools/draw_trade_stall.ts、generate_wilds
      の 「the trade」)
- [x] **4. 道具の出番**: りんご・魚 (docs/item-tools.md)
      の使いどころを島に置く。 道具を持って歩く理由になる (作った:
      島のあちこちに動物の試練の部屋 6 つ。
      板に乗っている間だけ開くドアの奥に宝。りんごの部屋はチェイサー、魚の部屋は猫、
      両方の部屋は 2 枚の板と 2
      枚のドア。りんごは持ち込むか外の苗木が育つのを待つ、魚は中の池で釣る。
      generate_wilds の「the animal trials」)

## 歩いた先のご褒美

- [x] **5. 近道を開く**: 一度遠くまで行くと、帰り道を短くする仕掛け
      (はね板、渡し船、ワープの石碑) が使えるようになる。行った所ほど楽に戻れる
      (作った: 歩くと遠回りなのに数マスしか離れていない所 (川・木立・岩越し) に
      通り道を切り、閂の門を置く。閂は着地点から遠い側にあり、遠回りして向こう側から
      押すと開いて近道になる。model/shortcut.ts、tools/draw_latch_gate.ts、
      generate_wilds の「the shortcuts」)
- [x] **6. 石碑ワープ**: 名所ごとに石碑を置き、触れるとそこへのポータルが START
      の部屋に加わる。開くには自分の足でそこまで行く必要がある (作った: 名所 7
      か所と洞窟の入口のそばに石碑の環、START
      の通路の西に石碑の広間。石碑の横の門からは広間へ帰れる。
      model/waystone.ts、tools/draw_waystones.ts、generate_wilds の「the
      waystones」)

## 目的地としての特別な場所

- [x] **9. 島の四隅の秘密**: 北の雪原、南の沈んだ遺跡 (SUNKEN RUINS)、東の岬
      (EAST CAPE)、西の街の地下水道。それぞれに 1 つずつ大きな謎を置く (作った:
      四隅それぞれに大きな試練 (雪原は氷、沈んだ遺跡は岩、岬はスイッチ、
      地下水道は迷路)。奥にある空の窓枠に、ばらばらの窓のかけら
      (雪原・海・町・空) の合うものをはめると景色が戻り 25 コイン、4
      つそろうとさらに 100 コイン。
      model/pane.ts、tools/draw_panes.ts、generate_wilds の「the four corners」)
- [x] **10. 運河と川を舟で**: SOUTHPORT
      の運河や島の川を渡し舟で下る。川はどれも水源か港から海までつながっている
      (generate_wilds の「rivers made whole」)
      ので、川下りがそのまま島を縦断する道になる (作った:
      川の水源と街のいちばん奥の運河から海までの水路に沿って、100
      マスほどごとに舟着き場と舟。岸から舟に
      ぶつかると乗り込み、次の舟着き場まで漕いで運ばれて岸に降りる。河口の舟は
      最初の舟着き場まで川を上って戻る。model/ferry.ts、tools/draw_ferry.ts、
      generate_wilds の「the ferries」)

## 作るときに守ること

- docs/design-principles.md の原則に合わせる:
  説明より先に見せる、看板は仕組みを書いて解き方は書かない、失敗は安く
- 見た目は docs/art-guide.md の通り、パレットの色だけ
- 生成で置くものは generate_wilds の検証 (届かない所がない、など) に通す
