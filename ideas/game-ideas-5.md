# 町で暮らしているアクターのアイデア集 (第5弾)

町を「人が住んでいる場所」に見せるためのアクター。どれもプレイヤーとは無関係に
自分の用事で動き、近づくと反応する。パズルの駒ではなく、町の空気を作る役。

実装は `model/townsfolk.ts`、移動の小道具 (向かう・離れる・経路探索) は
`model/steering.ts`。

## A. アクター

### A-1. 住人 【actor `villager` / `villager2` (idle・pushed `villager`)】

- 家 (出現マス) から 10 マス以内の **目印** (店・テーブル・椅子・看板・
  ランタン・宝箱・祠・苗木) を 1 つ選び、幅優先探索の最短経路で歩いていく。
  椅子なら座り (上に乗る)、それ以外は隣に立って目印の方を向く
- 着いたら 2〜5 秒たたずみ、次の目印へ。同じ目印を続けては選ばない。 3
  件用事を済ませると家に帰って 5〜10 秒休む
- 道がふさがっていたら 1 秒待ち、だめならその用事をあきらめる
- **立ち話**: 歩いている途中で別の住人と隣り合うと、2 人とも立ち止まって
  向かい合い、白い吹き出し (パフ) を出しながら 2.5 秒話す。その後 15 秒は
  立ち話しない
- 体当たりされるとそちらを向き、プレイヤーなら一言しゃべる
  (セリフは住人ごとに順番に回る)

### A-2. 店番 【actor `keeper` (idle・pushed `keeper`)】

- 屋台 (shop) の後ろの持ち場から動かず、5 マス以内で一番近い人の方を向く
- プレイヤーが 3 マス以内に来ると一度だけ「WELCOME! TAKE A LOOK」。 6
  マス以上離れたら次の来店でまた挨拶する
- 誰もいないと 5〜9 秒ごとに 1 歩横へ動いて片付けをし、1〜2 秒で持ち場へ戻る
- 体当たりされると店のセリフを順番に言う

### A-3. 子ども 【actor `kid` (idle・pushed `kid`)】

- 子ども同士で **鬼ごっこ**。周りに鬼がいなければ誰かが鬼になり、黄色い パフで 3
  つ数えてから、一番近い子を **2 倍速** で追う。ぶつかったら鬼が
  交代し、新しい鬼がまた 3 つ数える
- 鬼でない子は 4 マス以内の鬼から逃げ、それ以外は家の周り 8 マスで遊び回る
- **プレイヤーも参加できる**: 鬼が 6 マス以内のプレイヤーを捕まえると 「YOU'RE
  IT!」。プレイヤーが子どもに体当たりすると鬼を返せる
  (子どもは時々息切れして止まるので追いつける)。プレイヤーが遠くへ行くと
  鬼は子どもたちに戻る

### A-4. 猫 【actor `cat` (idle・pushed `cat`)】

- 4〜10 秒昼寝して、周り 4 マスを 1〜3 歩散歩する。これを繰り返す
- 見知らぬプレイヤーが 2 マス以内に来ると、ゆっくり離れる
- 体当たり = **なでる**。ピンクのパフと「PURR...」で、10 秒間プレイヤーの
  後をついてくる。飽きたらその場を新しい寝床にする

## B. 置き場所

- プレビュー動物園の `TOWN` (block_10000.10000 の南): 石畳の広場、家 3 軒、
  屋台と店番、噴水とベンチ、住人 4 人、子ども 3 人、猫 2 匹
- 地上の村 (block_200.-200 と block_-400.200):
  `deno -A tools/modify_map_add_townsfolk.ts` で、各家のテーブルの横に住人、
  十字路の脇に屋台と店番、十字路の南東で遊ぶ子ども 3 人、猫 2 匹を置く。
  何度実行しても同じ結果になる (前回置いた町の人と屋台を消してから置き直す)

## C. ドット絵

アクターはグレースケールだけで描く規則 (docs/art-guide.md) なので、既存の
灰色の町人 (lena / juni / joob / kimi) の輪郭を使い、明暗の入れ替えで
描き分けた。猫は新しく描いた。

| アクター  | 元     | 描き分け                                     |
| --------- | ------ | -------------------------------------------- |
| villager  | lena   | 暗い髪 `#4a4d4a`、明るい服 (lena の逆)       |
| villager2 | juni   | 明るい髪と服 `#b9bcb9` (juni は中間のグレー) |
| keeper    | joob   | 暗い髪、体に白いエプロン                     |
| kid       | kimi   | 暗い髪、白と灰の横縞のシャツ                 |
| cat       | (新規) | 灰色の縞猫、白い口元と胸                     |

## C'. 町のプロップ

[kt3k/ff5study](https://github.com/kt3k/ff5study) の FFV の町タイル (16x16)
を元にした。プロップもグレースケールだけ。

| プロップ             | 元のタイル                                                          | 取り込み方              | 性質                       |
| -------------------- | ------------------------------------------------------------------- | ----------------------- | -------------------------- |
| `sign-inn` など 6 種 | 02_town_exterior_1 の最下段 (INN / 武器 / 防具 / 道具 / 魔法 / PUB) | 輝度をグレーに割り当て  | 通れない。店の入口に掛ける |
| `barrel`             | 02_town_exterior_1 の樽                                             | 同上                    | 通れない                   |
| `jar`                | 06_town_interior の壺                                               | 同上                    | 通れない                   |
| `notice-board`       | 02_town_exterior_1 の掲示板                                         | 同上 (背景の草は透明に) | 押すと読める (看板と同じ)  |
| `well`               | 02_town_exterior_1 の井戸                                           | 形を借りて描き直し      | 通れない                   |
| `flowers`            | 02_town_exterior_1 の花                                             | 形を借りて描き直し      | 通れる                     |

住人はこれらも用事の行き先 (目印) にする。

## D. 今後のアイデア

- 住人の家を覚えさせ、ドアから出入りさせる (家の中の床を家とみなす)
- 時間帯の代わりに「町の鐘」で全員が広場に集まる行事
- 住人のセリフを看板と同じくマップのデータで指定できるようにする
  (アクターのスポーンに `data` を持たせる)
