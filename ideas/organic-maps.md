# 有機的なマップ生成 (WILDS)

既存の地上は「ブロックごとのテーマ」「全ブロックを貫く十字の道」「長方形と円」
「一様ランダムな配置」でできていて、単調で人工的に見える。その代わりの作り方を
既存の世界とは別の場所で試す。それが **WILDS** (`block_2000.0` から 14x9
ブロック = 2800x1800 マスの島、はじめは 4x3、のちに 8x5) で、START
の「W」部屋のポータルから行ける。

`deno task generate-wilds` で生成する (`tools/generate_wilds.ts`)。
`--preview <file.png>` を付けると、地形の種類を色分けした 1 マス 1 ピクセルの
画像も書き出す (調整用)。

## 計画 (手で置く「錨」)

`tools/wilds_plan.json` に要所だけを書く: シード、着地点、村 (名前と家の数)、
名所 (見晴らし台・祠・遺跡)、キャンプの数、洞窟の口 (CAVE
MOUTH)。位置は島に対する割合で書き、生成器が
近くの建てられる土地に合わせる。あとは全部生成器が埋める。

## パイプライン

1. **島全体で 1 枚の場**: 標高と湿り気を世界座標の fBm ノイズで作る。座標を
   別のノイズでずらし (ドメインワーピング)、中心からの距離で海へ落とす。
   ブロックは切り出しにすぎないので、境目に継ぎ目がない
2. **川**: 高いところから海への「一番安い道」を探す。下りはほぼ無料、上りは
   高くつくので谷を流れる。上らざるを得ない窪みでは池になる。なめらかな
   ノイズをコストに足して蛇行させる。川の周りは湿る
   (後から山・街・町・道・入り江・パズル部屋が上に置かれて川が途中で切れるので、
   最後にもう一度、それらを避けて水源から海まで流し直す。古い流れは干上がる。
   街の運河が街の縁に出る所からも川を海まで流す。どの川も運河も海に届くことを
   生成時に確かめる)
3. **地形**: 標高 x 湿り気で 海 / 砂浜 / 草地 / 森 / 丘 / 岩 に分け、低くて
   湿った所は湖にする。近傍 8 マスの多数決で数回ならして塊にする
4. **錨**: 計画の場所 + 互いに離れたキャンプ。地面を広場・石畳にする
5. **道**: 錨を最小全域木でつなぎ、村から 1 本ずつ輪を足す。各辺を A* で引く
   (海は不可、岩・湖は高い、川は橋になる、起伏も高い)。コストにのせた
   なめらかなノイズで道が曲がる
6. **村**: 広場 (井戸・屋台と店番・掲示板・ランタン・子ども) と、道沿いに
   道を向いて建つ家 (入口から道への小道、家具、住人、看板)。周りに羊
7. **散らばり**: ポアソンディスク (一定以上離れた点) で、密度に場所の意味を
   持たせる。森には木 (1〜4 マスの塊)、丘には岩、水辺に花、道から遠いほど
   コイン、木の下にりんご、森の奥にきのこ・チェイサー、水辺にカラス、道に 通行人
8. **全部行ける**: 着地点から歩いて届かない場所があれば、大きければ木や岩を
   切り開いて小道を通し、小さければ木で埋める。最後に全錨へ届くこと、
   届かない歩けるマスがないこと、村に家が 3 軒以上あることを確かめる

## 町の型

`wilds_plan.json` の村ごとに `layout` で型を選ぶ (家の数は `houses`)。町の 土地
(半径 24〜30) は牧草地にならし、通り・城壁・池を **道より先に** 敷く。 道の A*
は城壁と家を通れないので、道は通りにつながり、城壁の町には門から
入る。家は通り沿いに、通りに戸を向けて建つ。

| 型           | 町        | 作り                                                                                |
| ------------ | --------- | ----------------------------------------------------------------------------------- |
| `crossroads` | ASHFORD   | 広場で交わる 2 本の大通り、沿道の家と街灯、通りの端に衛兵                           |
| `ring`       | MILLBROOK | 真ん中に池、周りの緑地にベンチ、外側に環状の通りと 4 本の放射路、家は緑地に向く     |
| `walled`     | STONEGATE | 四角い城壁と 4 つの門、中は碁盤の目の通り、中央広場に市場と王女の一行、門ごとに衛兵 |
| `market`     | HAYWARD   | 長い市場通りに屋台と店番、裏通りに住まい、東の端に畑 (耕した土 `t` と苗木の列)      |

町の人は役 (`model/townsfolk.ts`) で動く: 衛兵は持ち場から見回り、吟遊詩人と
踊り子は演奏して人を集め、魚売りと船乗りは岸で釣り、農夫は畑の苗を世話し、
賢者と修道女はベンチに座り、商人は遠くの名所を回り、見習いは掃除をし、
宰相は王女について回る。

## 市街地 (CITY)

WILDS の島の西の海岸にある 400x400 マスの市街地 (2026-10 に島の中へ移した)。
島を 14x9 ブロックに広げたとき (2026-10)、南に同じ規模の 2 つ目の街 SOUTHPORT を
足した。同じ生成器を「様式」(`style`) で切り替えて、2
つの街に別の性格を持たせる。 街は `tools/wilds_plan.json` の `cities` に並べる
(1 つ目が C ポータルの着く CITY)。

| 様式      | 街        | 特徴                                                                                                                                                                                          |
| --------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `capital` | CITY      | 城下町。石造りの家、石畳の大通り、運河は 1 本、東に城壁と天守の城、衛兵と通勤の人                                                                                                             |
| `canal`   | SOUTHPORT | 運河の漁師町。木造の家と砂岩の店、板張りの大通り、縦横にうねる運河 (真ん中に幅広の大運河)、細かい区画、倍の桟橋と先の灯り、城の代わりに生け垣に囲まれた砂岩の神殿と池、漁師・船乗り・猫が多い |

通りの位置、外形の揺れ方、地区の並びと名前 (港 WHARVES、網職人 NETMAKERS、 神殿
TEMPLE、造船所 BOATYARD など) も様式ごとに違う。運河で道から切り離された
建物は取り壊して木立にする。 街の輪郭も有機的にした:
港の海岸側はまっすぐ、北・東・南は丸くてぎざぎざの D の形
(ノイズで揺れ、城のまわりは丸く膨らむ)。正方形の残り (`CITY_OUT`) は島の
地形になり、木の帯は輪郭に沿う。大通りは輪郭の所で門になって終わる。
島の道が街の北・南・東の門まで来ていて、歩いて入る。`tools/generate_city.ts` の
`buildCity()` が作って検証し、`deno task generate-wilds` が島に置く
(`generate-city` 単体は検証とプレビューだけ)。

1. **地面**: 西に海と港の岸壁、南北に曲がって流れる運河、幅 4 の大通りが 縦横 2
   本ずつ。大通りが土地を 9 つの地区に分ける (港・北区・市場・南区・
   山の手・城・公園区)
2. **区画**: 地区ごとに、長い辺を通り (幅 2) で切ることを区画が十分小さく
   なるまで繰り返す (二分空間分割)。切る位置を揺らすので、碁盤の目にならず
   不規則な街区になる
3. **建物**: 区画を地区の性格で建てる。住宅地は通りに戸を向けた家の列、
   市場は看板と店番のいる店の列、港は倉庫 (木箱と樽の列) と桟橋、城は城壁
   と門、天守、兵舎、果樹園。特別な区画として広場 (井戸と触れ役)、露店市、
   魚市場、公園 (池・ベンチ・木)、礼拝堂と墓地
4. **人**: 家ごとに住人 (地区ごとの顔ぶれ)、店ごとに店番、通りに点灯夫・
   通勤者・買い物客・物乞いなど。役は `model/townsfolk.ts`
5. **検証**: 橋から全部の床に歩いて行けること (届かない空き地は木で埋め、
   家具でふさがった狭い店は家具を除く)、すべての戸に届くこと、家・店・倉庫の
   数、出てくる種類がすべてカタログにあること

## 見た目のルール

- 地形はグレースケールのまま: 海・湖・川 `w`、砂浜 `y`、草地 `6`、森の地面
  `f`、木 `2`、丘 `p`、岩 `1`、道 `3` (草地と見分けるため floor2)、橋・家の床
  `d`、広場 `c`、祠・遺跡 `m`、畑 `t`
- 部屋名 (画面左下の表示) は村・名所・キャンプの名前 (`WILDS-ASHFORD` など)
- 名所「BONE VALLEY」(骨の谷): 生体機械の壁 `A`〜`F` (docs/art-guide.md)
  の丸い殻に 4 つの入口、内側へ伸びる 8 本の肋骨。向きごとに壁の種類が変わる。
  真ん中に自分の像・月の殻・時計・宝箱、影が 2 つうろつく
- 壊れる物と人でない生き物 (ideas/breakables.md) を、道・村・名所から離れた
  開けた土地に種類ごとに 3 つずつ散らす。岸には歯磨き粉の山、水から 2 マスの所に
  かたつむり、鐘の石は 5 つ並べて看板つき

## 洞窟 (WILDS CAVERN)

洞窟は WILDS の島の中にある (2026-10 に作り直した)。島の南の真ん中に山があり、
その中が 400x400 マスの洞窟になっている。北の斜面の「CAVE MOUTH」まで道が
来ていて、口から幅 3 マスの通路で山の岩を抜けると洞窟の大広間に出る。ポータル
もトンネルも橋も使わない。

- 洞窟は `tools/generate_cavern.ts` の `buildCavern()` が作って検証し、
  `deno task generate-wilds` がそれを山の中に押す (`generate-cavern` 単体は
  検証とプレビューだけ)。位置は `wilds_plan.json` の `cave` (入口の列 `x`、
  上端の行 `y`、どちらも島に対する割合)
- 高さの場に「山」を足す: 洞窟の四角 (と周り 14 マスの岩) からの距離が
  近いほど地面が持ち上がるので、山は丘と岩場のすそ野に囲まれ、川はそこから
  流れ下る。四角の中は岩で埋め、最後に洞窟を押す。洞窟の岩 (`2`) は山の岩 (`1`)
  に置き換えて継ぎ目を見せない
- 島はその分大きくした (4x3 ブロックから 8x5 ブロック)。村や名所は山と
  街をよけて置き直した
- 市街地 (CITY) も島の中にある。`tools/generate_city.ts` の `buildCity()` が
  作って検証し、`generate-wilds` が島の西の海岸 (`wilds_plan.json` の `city`)
  に置く。街の港の海は北と南で外海につながり、街のまわりの土地は低く
  (丘や岩にならないように) 持ち上げる。大通りは街を囲む木の帯の門を抜けて外へ
  出て、島の道はその門 (北・南・東) まで来る。東の桟橋と長い橋はなくした

広い所は「描かずに育てる」、狭いパズルの部屋は「四角いまま検証する」。

1. **ミッショングラフ**: 入口 -> 大広間 (HALL) -> 地底湖 (LAKE)・晶洞
   (GROTTO)・深部 (DEEP) -> 3 つの試練 (鍵 1 本ずつ) -> 鍵の門 3 つの奥の宝物庫
   (VAULT)。輪になる辺も足して、行き止まりの木にしない
2. **部屋 (プレハブ)**: 試練と宝物庫は小さな四角い「古い石室」として先に押し、
   周りを岩で固めて後の段階で触らない
   - TRIAL1: 水路で分かれた部屋。岩を水に押して橋にする
   - TRIAL2: 氷の部屋。生成して解いて試す (6 手以上、帰り道もある配置だけ使う)
   - TRIAL3: レーンの先の感圧板に岩を転がして乗せると、仕切りの扉が開く
3. **空洞**: 各ノードをメタボール (中心からの距離) で開け、縁を fBm ノイズで
   でこぼこにする。どのノードからも遠い所はノイズだけでは開かない。湖は
   ノイズでゆがめた楕円。主な空洞の間に小さな「NOOK」を数個足し、一番近い
   主な空洞へつなぐ (暗く、コインやきのこがある)
4. **通路**: グラフの辺ごとに A* で岩を掘る。コストにノイズをのせて曲げ、
   水はなるべく避ける。太さはノイズで 1〜2 マスに変わる
5. **ならし**: 近傍 8 マスの多数決で角を丸め、床をノイズで砂利・砂・土に
   塗り分け、晶洞には石畳の結晶。ポアソンディスクで石筍、酔歩で脇の小部屋
   (コイン)
6. **検証**: 入口から届かない床は、小さければ埋め、大きければ一番安い道で つなぐ
   (水の上は板の橋)。各試練が解くまで閉じていて解けること、宝物庫が 鍵 3
   本でだけ開くこと、届かない床がないことを確かめる

部屋名は `CAVERN-HALL`、`CAVERN-TRIAL2` など。

## これからの課題

- 境界の装飾: 水と陸、森と草地の境目に縁取りを描画時に足す (cell-decor)
- 川の一部がまっすぐ流れる区間がある (斜面が急すぎる所)
- 錨をもっと増やす (橋のたもとの小屋、灯台、峠の茶屋など) と道に目的が増える
- うまくいったら既存の地上 (`generate_map_blocks.ts`) をこの方式に置き換える
