# ボタンと連動して動く壁のアイデア集 (第3弾)

第2弾 (game-ideas-2.md) の圧力スイッチ + ドア (A-1) は「踏んでいる間だけ開く」
瞬間式だった。ここでは **押しボタン (押す = バウンス) と連動して動く壁**
のバリエーションを考え、それぞれをパズル部屋に落とし込む。

共通の設計:

- ボタンは `pushed` デリゲート、壁は `step` で自分のグループの状態を見て
  `canEnter` を切り替える。状態はモジュールレベルの Map に持ち、
  部屋を出入りしても (prop の非アクティブ化を跨いでも) 保たれる
- 壁は **誰かが立っている間は閉じない** (door と同じ)。閉じ込め事故を防ぐ
- ボタンは **誰が押しても反応する**: プレイヤー、跳ね返り NPC、転がる岩。
  「ボタンを押す主体」を増やすことがパズルの幅になる
- 開閉の見た目は growth 画像 (2 段階: 立っている / 沈んでいる) で表現する

## A. ボタン連動壁のギミック案

### A-1. トグルスイッチ + 青壁/赤壁 【実装: switch / blue-wall / red-wall】

- `switch` を押すたびにグループの ON/OFF が反転する。`blue-wall` は OFF
  のとき立ち、ON のとき沈む。`red-wall` はその逆
- 青と赤は常に片方だけが立つ = **エアロック**。青を抜けて中間部屋に入り、
  もう一度押して赤を抜ける、という手順が自然に生まれる
- スイッチの結晶の色 = 今立っている壁の色、で状態を伝える

### A-2. 全点灯パズル (AND 壁) 【実装: switch の `also` / and-wall】

- `switch` に `also: string[]` を持たせると隣のグループも一緒に反転する
  (ライツアウト式)。`and-wall` は `groups` のすべてが ON のときだけ沈む
- 3 スイッチ・3 グループで「真ん中を押すと 2 つ戻る」ような
  排他的論理和のパズルが作れる。青壁を「インジケータ」として並べると
  現在の状態が一目で分かる

### A-3. タイマーボタン + シャッター 【実装: timer-button / shutter】

- `timer-button` を押すと同グループの `shutter` が `duration`
  フレームだけ開く。既存 timer-gate との違いは **ボタンと壁が離れている**
  こと。ボタンからシャッターまでの道のりそのものが問題になる
- 素の速度ではギリギリ、きのこ (2x) なら余裕、という距離に調整する。
  ショップのきのこの使い道になる

### A-4. 順番ロック 【実装: seq-button / seal-wall】

- `seq-button` は `order` を持ち、グループの「次の番号」と一致すれば 押下が確定
  (点灯)。飛ばして押すとリセット (全消灯 + 警告音)
- `seal-wall` は `count` 個すべてが正しい順で押されたら開く。以後は開いたまま
  (部屋の再入場でも保持)
- 番号の札 (`1_white` など) を **順不同に** 置いて「読ませる」

### A-5. スライド壁 (動く隙間) 【実装: slide-button / slide-wall】

- 一直線に並べた `slide-wall` (各自 `index`) のうち、ちょうど 1 枚だけが
  隙間になる。`slide-button` を押すたびに隙間が 1 つ隣へ移動する (循環)
- 隙間の先が壁だと意味がない = 「何回押せば目的の小部屋に合うか」を
  数える。押しすぎたら一周回せばよい

### A-6. パトロール NPC がボタンを押す 【実装: actor `patrol`】

- `patrol` は idle で今向いている方向へ歩き出し、`inertial` で跳ね返る。
  片端がスイッチの 1 マス幅レーンに閉じ込めると **一定周期でスイッチを
  叩くメトロノーム** になる
- 青壁と赤壁を直列に置けば「青が沈んだら中に入り、ポケットで待ち、
  赤が沈んだら抜ける」という周期パズル。プレイヤーはレーンに入れないので
  自分で押して壊すことはできない

### A-7. 岩でボタンを押す 【実装: boulder の roll がぶつかった prop を押す】

- 転がる岩は止まった先の prop に `onPushed` を送る。ボタンは誰の押下でも
  反応するので **遠隔・遅延押し** ができる (岩がレーンを転がっている間に
  自分は別の場所へ移動する)
- 「スイッチを ON にして青壁を抜け、中で待っているうちに岩が届いて OFF
  になり赤壁が沈む」= 一人でエアロックを通す解法
- 副産物として岩は木箱や宝箱も壊す (break 系は押し主を問わない)

## B. 組み込み先

### B-1. チュートリアルコース (block_-200.0)

- パズルダンジョンへのポータル小部屋を青壁で塞ぎ、通路にスイッチを置く。 「押す
  → 壁が沈む」の最小構成をここで教える

### B-2. パズルダンジョン B1F の R8「スイッチの試練」 (block_-400.400)

中央通路と東通路の間の未使用帯 (x 104..120, y 68..134) を縦に 7 部屋に
区切り、上から順に解いていく一本道にする。最後は一方通行ベルトで 中央通路
(金庫前) に戻る。

| 部屋 | ギミック                     | 問題                                                   |
| ---- | ---------------------------- | ------------------------------------------------------ |
| A    | A-1 青/赤エアロック          | 入口と中間室の 2 つのスイッチで交互に抜ける            |
| B    | A-6 パトロールのメトロノーム | 周期的に反転する青→赤の直列壁をポケットで待つ          |
| C    | A-3 タイマーラン             | ボタンからシャッターまで 28 マスを 8 秒で走る          |
| D    | A-5 スライド壁               | 隙間を 4 回ずらして出口のある小部屋に合わせる          |
| E    | A-4 順番ロック               | 札の番号順 (配置は順不同) に 3 つ押す                  |
| F    | A-2 全点灯                   | 隣を巻き込むスイッチ 3 つで全部 ON にする              |
| G    | A-7 岩の遅延押し             | 岩を転がしてから青壁の奥へ走り、届いた岩で赤壁を沈める |

各部屋は「失敗しても部屋を出て戻れば岩が復活する」既存ルールに従う。
