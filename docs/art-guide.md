# ドット絵の色ルール

これまで色の決まりはコミットメッセージ (dc4747b) とコード中のコメントに
しかなかったので、ここに明文化する。

## パレット

- すべてのピクセルアート (セル / アイテム / プロップ / アクター / エフェクト /
  UI) は [kt3k/vscode-pixeledit](https://github.com/kt3k/vscode-pixeledit) の
  パレット (`src/webview.ts` の `paletteColors`、不透明色 54 色) の色だけを
  使う。正本は `util/palette.ts` の定数 `Palette`。
- コードで色を使うときは `#xxxxxx` を直接書かず、`Palette.gray2` のように
  定数を使う。エフェクトやセルの色を受け取る API は型 `PaletteColor` しか
  受け付けないので、パレット外の色を書くと型検査 (`deno task check`) で 止まる。
- `deno task check-palette` は、`static/` 配下の全 PNG の画素、カタログの セルの
  `noise` の色、`static/index.html` に書かれた `#rrggbb` を検査する。
  パレット外の色が 1 つでもあれば失敗する。素材を追加・変更したら必ず実行 する
  (例外は素材の元絵 `static/actor/lena.png` のみ)。
- 1 スプライトの色数は 16x16 なら 4〜6 色まで (輪郭 + 基本色 + 影 + ハイライト
  - 差し色)。

定数名は「色相 + 段」で、段 1 が最も明るく 4 が最も暗い。グレーは白から黒へ
順に並べてある。

## 画面に出す色の方針

**画面に表示される色は、すべてパレット (`util/palette.ts`) の色でなければ
ならない。** スプライトだけでなく、描画の結果として画面に出る色すべてが
対象で、パレット内の色同士を混ぜてできる中間色も認めない。

そのため次のことはしない。

- 半透明の重ね塗り (`rgba()` / `hsla()` のアルファ、`globalAlpha`、CSS の
  `opacity` を 0 と 1 以外にする、Tailwind の `bg-black/80` など)
- グラデーション (`createRadialGradient` / `createLinearGradient`、CSS gradient)
- フェードやクロスフェード (`opacity` や色の CSS `transition`)
- 合成モードやフィルタでの色の変化 (`globalCompositeOperation` で色を作る、CSS
  `filter`、`blur`、影)
- 拡大縮小や回転での補間 (`imageSmoothingEnabled` は false、CSS は `crisp-edges`
  / `pixelated`、回転は 90 度単位で整数の行列だけ)
- パレット外の UI 色 (Tailwind の `text-gray-400` など)

明るさを変えたいときは、パレットの隣の階調に置き換えるか、ディザ (市松
などのパターンで黒を置く) で表現する。例: 壁の土台の縁 (`casts`) は黒の
市松。夜の暗転はこの方針に反するため削除した。

### 文字

- フォント `8bit` (vaticanus) は 8px グリッドで作られている (1em = 1024
  units、1px = 128 units) ので、8px か 16px でだけ使う。それ以外の
  サイズではドットが画面の画素にそろわず、にじむ。
- 文字にはクラス `pixel-text` (16px、`pixel-text-sm` を足すと 8px) と インク
  `ink-white` / `ink-light` / `ink-mid` を付ける (`static/index.html`)。
  インクは SVG フィルタで、半分以上覆われた画素だけを残してパレットの 1 色
  (`#ffffff` / `#b9bcb9` / `#6a6d6a`) で塗る。ブラウザの文字の
  アンチエイリアスは CSS では確実に止められないため、この方法で中間色を
  消している。
- インクは要素全体を 1 色にするので、背景色を持つ要素には付けない。背景は
  外側の要素に、インクは内側の文字だけの要素に付ける (メッセージトースト
  がその形)。

### 演出

- 読み込み中のチャンクは黒で覆い、描き終わったら黒の市松を 150ms 見せて から消す
  (フェードの代わり)。
- アイテム取得の演出は位置だけ動かし、透明度は変えない。
- 同じマスに重なったアイテムはまとめて取れる。2 個以上のときはマスの上に
  「×N」(白に黒の 1px 縁取り) が浮かび上がり、少し止まってから一度に消える
  (`countPopup`、model/effect.ts)。右上のカウンターへは取った数だけ (最大 5 個)
  アイコンが続けて飛ぶ。
- アイテムを取った時に四方へ飛ぶ線は、**そのアイテムの絵で一番多く使われて
  いる色** で描く (コインは金、リンゴは赤、宝石は緑)。数えるのは絵の中身だけで、
  どのアイテムにもある外周の `gray2` の輪と黒の輪郭は数えない。色は
  `tools/item_colors.ts` が絵から求めてカタログ (`items.<type>.color`) に書き、
  `deno task check-palette` が絵と合っているかを確かめる。アイテムの絵を
  描き直したら `deno -A tools/item_colors.ts` を実行する。
- 宝箱の中身は押した人のマスには落ちない (跳ね返りで気づかないうちに取って
  しまうため)。ほかの空いた辺に散り、行き場がなければ宝箱のあったマスに山に
  なる。DEBUG マップの「STACKS」で山を作って試せる。
- 壊れる手応え (ideas/breakables.md): ヒットストップ (数フレーム世界を止める)、
  1px の揺れ、破片 (パレットの色の小さな四角が飛んで落ち、一度に消える)、割れた
  マスに 2 フレームの白い四角。どれも半透明やフェードは使わない。
- 壊れる演出の研究ページ: `effects.html` (game/effects.ts、model/break-fx.ts)。
  少ない動きで見せる: 新しい物を出さず、物の絵のピクセル (と押した時の線) を
  ずらす・切る・落とす・線に変える。消す時はパッと消さず、マスの床の線の外へ
  出す。候補は、ずれて割れる・潰れる・沈む (列ごとにずり落ちる)・押し出されて
  崩れる・消える行が線になる・押した線が貫く・割れ目が走る・砂になる・がれきが
  残る・色を段階的に落とす (フェードに当たるかは要判断)・止め + 揺れ + 減速
  ワイプ。各ステージに「動きの量」(変化した画素数、前後の frame の 1px 以内に
  何もない「急に出た / 消えた」画素数) が出る。静かなプリセットで急に出る画素が
  0 なことを `model/break-fx.test.ts` が確かめる。前の NES 風の候補
  (レンガ割り・ 煙・玉・星など、動きが多い) は「前の候補」に畳んである。設定は
  URL に入るので
  共有できる。どのパターンもパレットの色とドット単位の座標しか描かない。
- 画像は `img` / `canvas` すべて `image-rendering: pixelated` なので、
  高解像度の画面で拡大されても補間されない。

### 確認のしかた

ヘッドレスブラウザで画面を撮り、パレットにない色の画素を数える。 2026-09
の時点で、読み込み直後、静止時、トースト表示、アイテム取得の
途中、チャンク読み込みの覆いが出ている間、のどれも、デバイスピクセル比 1 と 2 で
0 画素だった。

## 地形セル (static/cell)

地形は **グレースケール** に限定する。キャラクター・アイテム・仕掛けが色で
浮き上がって見えるようにするため。

**例外: 水 (`w` とその変種) だけは青系を使う。** 水と陸の区別は遊びに直結する
(歩けない・橋を架ける・釣りをする) ので、ひと目で分かる色にする。使ってよいのは
パレットの青 4 階調 (`blue1`〜`blue4`) だけで、それ以外の色・パレット外の色・
半透明は使わない。水に浮かぶハス (睡蓮) の葉は緑系 (`green1`〜`green4`) を
使ってよい (花は白)。それ以外の水に浮かぶ物はほかの地形と同じくグレーで描く。
絵は `tools/draw_water.ts` が描く。

| 用途                              | 色                                                                      |
| --------------------------------- | ----------------------------------------------------------------------- |
| 床の地                            | `#b9bcb9`                                                               |
| 床の模様 (目地・小石・板の継ぎ目) | `#6a6d6a`                                                               |
| 床の濃い差し色 (影・砂利の黒石)   | `#4a4d4a`                                                               |
| 壁                                | `#b9bcb9` と `#000000`                                                  |
| 氷                                | `#ffffff` の地に `#b9bcb9` のひび                                       |
| 水 (例外: 青系)                   | `#1950c7` の地に `#68a5ff` の波頭、`#001480` の谷、`#cceaff` のきらめき |
| 森床                              | `#4a4d4a` / `#6a6d6a` / `#b9bcb9`                                       |

- 単色の床タイルは作らない。必ず 2 階調以上の模様を入れる (模様が薄くても、
  隣り合うタイルの継ぎ目が見えないことを 3x3 に敷いて確認する)。
- **色付きセル `g` (緑) / `a` (青) / `r` (赤) は地形に使わない。** 看板の
  文字を強調する背景専用。`b` (黒) は通行不可の目隠し。

## セルの単調さを崩す仕組み

16x16 のタイルをそのまま敷き詰めると模様の繰り返しが目立つので、描画時に
セルごとの変化を加える。すべて世界座標 `(i, j)` をシードにした決定的な乱数
なので、同じセルは何度描いても同じ見た目になる。実装は
`model/cell-decor.ts`、設定は `static/catalog/base.json` の各セル。

| フィールド | 値                              | 効果                                                                                                                             |
| ---------- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `noise`    | `色=本数[:形]&...`              | 色の小さな印をセル内にランダムに置く。形は `line` (既定, 横 1〜3px) / `dot` / `vline` / `speck` (小石) / `diag` (ひび) / `cross` |
| `flip`     | `h` / `v` / `hv` / `rot`        | セルごとに画像を左右・上下反転、または 90 度単位で回転する                                                                       |
| `variants` | `{ "../cell/x_a.png": 5, ... }` | まれに差し替える別画像。値は出現率 (%)。欠けた石・花・格子など「たまにある物」を置く                                             |
| `casts`    | `true`                          | 壁。真下のセルが壁でないとき、壁セル自身の下 2 行に黒の市松 (最下行は偶数列、その上は奇数列) を描いて土台の縁を出す              |

- `noise` の本数は一様ではなく、6 マス周期のなだらかな場 (0〜2 倍) で
  増減する。汚れが「まだら」に固まり、きれいなセルとの差が出る。均一に
  散らしたいセルは `"noisePatches": false` にする (レンガ壁 `2` がそう)。
- `flip` は方向性のない模様にだけ使う (石畳・砂利・氷・ひび・モザイク・ 森は
  `rot` / `hv`、板・砂紋・レンガは `h` のみ、ベルトと壁は使わない)。
- `variants` は 1 セルにつき合計 10% 前後まで。多いと「まれな物」でなく
  なる。差分画像は元タイルの上に 1 か所だけ手を入れる (`x_worn`, `x_crack`,
  `x_missing` のような名前)。
- 影はパレットのグレー 1 段
  (`#ffffff → #b9bcb9 → #6a6d6a → #4a4d4a →
  #000000`)
  を落とすだけなので、どの床の上でもパレット内に収まる。色付き
  ピクセルは変えない。
- 新しい床を足すときは、まず `noise` の形と `flip` を決め、必要なら `variants`
  を 1〜2 枚描く。`static/preview.html` でセルの横に variants が
  並んで表示される。

## アイテム・プロップ・アクター

- **アクターとプロップはグレースケールだけで描く**: `white` `gray1`〜`gray4`
  `black`。色付きで描いた既存素材もこの規則に揃えていく。区別は形と明暗で つける
  (例: 住人は元にした町人の髪と服の明暗を入れ替えている)。
- 町のプロップ (`well` `barrel` `jar` `flowers` `notice-board` `sign-*`) は
  [kt3k/ff5study](https://github.com/kt3k/ff5study) の FFV の町タイル
  (`materials/rom_extract/tilesets/02_town_exterior_1.png` など、16x16) を
  元にしている。看板・樽・壺は輝度をパレットのグレーに割り当てて取り込み、
  葉や地面を含むタイル (井戸・花壇) はグレーだと模様がつぶれるので形だけ
  借りて描き直した。
- kt3k/ff5study の `original/` (FF5 のルールで描かれたオリジナルの 16x16)
  から、町の人 17 人 + 子ども、キツネ、スライム、小物 6 種 (街灯・焚き火・
  テント・植木鉢・墓石・ベンチ)、アイテム 9 種 (宝石・金袋・剣・盾・巻物・
  ポーション・エーテル・薬草・パン) を `tools/import_ff5_originals.ts` で
  取り込んでいる。アクターと小物は FF5 の各色を明るさで 5 階調 (白・
  `gray2`・`gray3`・`gray4`・黒) に割り当て、髪・肌・服・持ち物が同じ階調に
  潰れないように人ごとに色の割り当てを変えている (肌は白、肌の影は
  `gray2`)。アイテムは近いパレット色に置き換え、縁の 1px を削って黒の輪郭と
  外周ピクセルを付ける。弓は弦の内側が穴として黒で埋まり読めなくなるので
  取り込まない。
- 家の中の家具 (ベッド・本棚・絵・燭台・地球儀・たらい) は FFV の町内装
  タイルセット (`06_town_interior.png`) から `tools/import_ff5_interior.ts`
  で取り込む。色ごとに明るさで 5 階調に割り当てるのは小物と同じ。シートの 紺
  (`#000073`) と黒の背景は透明に。1 マスより大きいベッドは中央の 16px
  列だけ切り出し、頭 (`bed-head`) と足元 (`bed-foot`) の 2 プロップで
  縦に並べる。絵 (`painting`) は家の壁マスの上に置く。家の中の小さな アイテム
  (本・ろうそく) は `tools/draw_interior_items.ts` で描く。
- グレーで潰れて読めない家具や FFV に無いもの (長テーブル `table-l`/`table-r`・
  背もたれ椅子 `chair`・トイレ `toilet`・浴槽 `bathtub-l`/`bathtub-r`・ シャワー
  `shower`・洗面台 `sink`・鏡 `mirror`・タオル掛け `towel-rack`・ 衣装だんす
  `wardrobe`・暖炉 `hearth`・敷物 `rug` (歩ける)・ほうき `broom`・ 窓 `window`)
  は `tools/draw_furniture.ts` で手描きする。トイレは 16px の
  ドット絵バスルーム素材に共通する形 (タンクと便鉢の 2 つの塊、間のくびれ、
  白い便座リングの中の暗い楕円) に寄せた。絵・鏡・窓は家の壁マスの上に
  置く。村の家は間取りの型 (`PLANS`: L 字のコテージ、翼のある農家、長屋、
  まれに両翼つきの屋敷、まれに台所と食堂が L 字の一部屋になった `ell`、
  入らなければ 2 部屋の小屋) から選び、通りを向くように
  回し、ランダムに鏡映する。型は長方形の部屋を壁線で接して組み、接した壁に
  戸口を切る (型は `tools/house_plans.ts` に共通)。`merges`
  に挙げた部屋の組は接した壁を端を残してぶち抜き、2 つの長方形が L 字や T
  字の一部屋になる (家具は長方形ごとに置く)。壁は家ごとに板壁 `V` か 石積み `M`
  (3 割) で、古さとは関係ない (壁は建て替えられるもの)。村には 通りより古い家が
  1〜3 軒あり、通りを気にせず建った後で通りの方が それを避けて通る (`street()`
  は直線を望みつつ家とその周囲 1 マスを迂回する
  経路探索)。古い家の戸口からは最寄りの通りへ小道が伸びる。古い家の敷地は
  あらかじめ「建てられない要素」(水・広場・城壁・畑・既存の家・地図の端) から 3
  マス以上離れたマスだけを候補にし、岩と砂は家の下と周囲 1 マスを草地に
  均して建てる。村の 5 つに 1 つには**変な家**がある: `growPlan` が部屋を 1
  つずつ継ぎ足して育てた 10〜20 部屋の家 (蛇・渦巻き・巣穴・碁盤) で、
  部屋はベッドだらけ・便所の列・本だらけ・ろうそくの部屋・がらんどう。育てる
  とき 7 部屋に 1 つは親の部屋との壁をぶち抜いて一部屋にし (碁盤は 3 部屋を L
  字に)、8 部屋以上の家には外壁に玄関が 1〜2 つ増える (`doors`:
  部屋の角を避け、他の玄関から 4 マス以上離す)。増えた玄関の先 2
  マスが水や岩や建物なら生成側が塞ぎ直し (`closeDoor`)、残った玄関からも
  それぞれ最寄りの通りへ小道が伸びる。都市は区画 (lot) の 建て方が地区で違う:
  港・南側・公園脇は「家が先」(`frontage`: 通り沿いに型の
  家を端から詰め、残りが庭になる)、山の手と城下は「区画が先」(`grid`: 区画を
  等分して長方形の 3 部屋の家を収める)、北側は区画ごとに交互。都市にも
  通りより古い家が 2 軒ある: 区画を切る前に地区の中に置いた 10〜20 部屋の変な
  家で、区画を切る通り (`streetRoute`) は直線を望みつつその家と周囲 1 マスを
  区画の中で迂回する。戸口からは最寄りの通りへ 1 マス幅の小道。3 つ目の都市
  CROOKHAVEN (スタイル `crooked`、西海岸の真ん中) は**ほぼ全戸が 変な家**:
  スタイルの `odd` で、通りより古い変な家を 10 軒狙い (地区ごとに
  上限を設けて港に偏らないようにする)、住宅の区画はすべて「家が先」で、
  どの区画も大きな変な家を試し、残りを埋める小さな家も型ではなく 2〜7
  部屋を育てた家にする (入らなければ型、最後に小屋)。区画は 1.5 倍に大きく、
  家の下限は 40 軒、家の 8 割以上が変な家であることを `generate_city`
  が検査する。 城の区画はどの都市でも**大きな変な屋敷**になった
  (`castle()`、`GRAND` で 味付け): 柵で囲った庭 (THE CITY は城壁、SOUTHPORT と
  CROOKHAVEN は生垣) の西門に玄関を向けて育てた 20〜40 部屋の変な家で
  (蛇・渦巻き・巣穴を先に試し、
  碁盤は最後)、増えた玄関は庭の砂利に開き、玄関の間の北壁は本棚、玄関の奥に 玉座
  (ランタン 2 つの間のテーブル)。THE CITY の keep は城壁の壁で本だらけ・
  寝台だらけ・ろうそくの部屋、宰相が玄関に、王女が最奥、衛兵と女騎士が間に、
  門に女騎士と衛兵、庭に苗木の列。SOUTHPORT の temple は砂岩の壁でろうそく・
  空き部屋・本だらけ・便所の列、賢者が玄関に、尼が最奥、尼と踊り子が間に、
  庭に池。CROOKHAVEN の mansion は城壁の壁で部屋は育った通り、発明家が玄関に、
  賢者が最奥、猫・尼・吟遊詩人・踊り子が間に、門に猫と子供。 他の 2
  都市にも大きな屋敷がある (スタイルの `mansion`: 区画を切る前に地区に置く
  20〜32 部屋の変な家で、地図上の部屋名を持つ): THE CITY の山の手には城壁の
  **ARCHIVE**
  (渦巻き・蛇、本だらけとろうそくの部屋、賢者と見習いと尼)、SOUTHPORT
  の漁師町には板壁の **LODGINGS**
  (巣穴、寝台だらけと便所の列、船乗りと魚売りと猫)。
- 住人との会話は**接触**で起きる: プレイヤーが隣のマスに立って相手を向いた瞬間に
  (`Actor.#checkContact` → delegate の `onContact`) 話しかけてくる。猫の撫で・
  子供の鬼ごっこのタッチ・迷子の案内・かくれんぼの発見も接触。相手にぶつかる
  (押す) のは別で、どの actor も一律に 1 マス押し出される (`onPushed` を持つ
  岩・巡回兵・珍獣など仕掛けの actor は従来どおり)。
- 変な家には専用の住人がいる (`model/oddfolk.ts`、生成側は `oddFolk`
  が家の部屋と 戸口を `data` で渡す):
  出口を探して部屋を巡り、やっと出てもすぐ戻る**迷子**
  (`lost`、正面から近づくと玄関まで案内を頼んでついてくる)、部屋の用途どおりに過ごす
  **部屋の番人** (`roomkeeper`: 寝台を順に寝る・便所の列に並ぶ・本棚を巡る・
  ろうそくを灯す・空き部屋の隅を歩く)、部屋を数えて回り毎回違う数を言う
  **数える人** (`counter`)、玄関から裏口へ家を近道にする**通り抜け**
  (`passer`)、部屋に隠れて鬼が探す**かくれんぼ**の子供
  (`hider`、正面から近づくと見つけた ことになる)。6 部屋から迷子、8
  部屋から数える人、裏口があれば通り抜け、10 部屋から子供 3 人 (20 部屋で 4 人)
  が付く。見た目は既存の住人のスプライトを使う。
- 輪郭は黒 `#000000` か濃い茶 `#3d1c00` / 濃い緑 `#253200`。ただし
  アイテムの輪郭は黒だけ (下の「アイテムの外周ピクセル」)。
- アイテムは下の「アイテムの外周ピクセル」の規則で描く。
- 金属・金は `#7f4b01` → `#d49d29` → `#f9e7b5` の 3 階調。
- コインはマリオのコインにならって、正面から見た縦長の楕円 (輪郭込み 8x12)
  にする。地は `#d49d29`、左の縁に明るい `#f9e7b5`、右の縁に `#7f4b01` の影、
  真ん中に縦の刻み (暗い線とその右に明るい線)。丸い円盤だと卵や石や種に
  見えてコインと分からない。
- 光源は左上固定。ハイライトは数ピクセル、影は右下に形として置く。
- 仕掛けの状態は色で伝える: 青 (`#002e55` / `#1950c7` / `#cceaff`) は 「OFF
  で立つ壁」、赤 (`#4f1000` / `#983600` / `#e58d68`) は「ON で立つ壁」、
  金は「ボタン・ゲート」。
- 16x16 の下 1 行は空けて奥行きを出す (門・壁・箱)。

## アイテムの外周ピクセル

アイテム (`static/item/` のドット絵) は、**輪郭のさらに 1px 外側を `gray2`
(`#b9bcb9`) の外周ピクセルで囲む**。りんごがこの形で、すべての
アイテムをこれに揃える。床の色 (白・グレー・黒) によらずアイテムが浮いて
見えるようにするため。

```
............    a = 外周ピクセル (gray2 #b9bcb9)
...aaaaaa...    b = 輪郭 (黒 #000000 だけ)
..aabbbbaa..    c = 本体の色
..abccccba..
..abccccba..    輪郭の角も外周で覆う: 輪郭 b が斜めでも
..aabbbbaa..    外 (.) に接してはいけない
...aaaaaa...
............
```

- 外周ピクセルは、外側の透明なところ (16x16 の端からつながった透明部分) に 8
  方向で接する不透明ピクセルのすべて。斜めの角も埋める
- 外周の色は `gray2` だけ。`gray1` など似た色を混ぜない
- 外周の内側 (外周に上下左右で接するピクセル) は輪郭にする。**アイテムの輪郭は黒
  `#000000` だけを使う**
  (濃い茶・濃い緑・グレーなどの暗い色で輪郭を描かない)。外周の `gray2`
  と黒の二段の縁取りで、どのアイテムも同じ見え方にするため。影など本体の
  暗い部分は輪郭の内側に置く
- アイテムに透ける穴は作らない。鍵の持ち手の内側のような穴 (外とつながら
  ない部分) は透明にせず黒で埋める (外周は置かない)
- 外周を含めて 16x16 に収める。大きさは外周込みで考える (コインは輪郭込み 8x12 +
  外周で 10x14、りんごは 14px)
- 描いたら `deno task item-ring static/item/<name>.png` で外周を足し、
  輪郭と穴を黒に塗り直せる。`deno task check-palette` が全アイテムを検査し、
  外周・輪郭・穴が規則に合わないピクセルの座標を出して失敗する
  (`tools/item_ring.ts`)
- 例外は表示用の代替画像 `static/item/not-found.png` だけ

## アクターの 4 方向フレーム

- `down` / `up` / `left` の 3 方向を描き、`right` は `left` の鏡像にする
  (左右で非対称なデザインのときだけ別に描く)。
- 横向きは 3/4 の横顔。頭の輪郭 (幅・高さ) は正面と同じにし、目を 1 つ
  進行方向側の縁に寄せる。後ろ向きは顔を描かず、帽子・髪・うなじで頭を 埋める。
- 頭の上端と足元の行は全方向・全フレームで揃える。上下のバウンドは入れない
  (既存アクターは足の入れ替えと胴体の揺れだけで歩きを表現している)。
- 2 フレーム歩行は「前足と後ろ足を入れ替える」+ 尻尾・腕などの付属物を
  逆側へ振る。正面で左右に振れるものは後ろ向きでも左右に振る。
- 参考: `static/actor/boco/` (正面 2 枚を元に横・後ろを起こした例)。

## 新しいセルの追加手順

1. `static/cell/<name>.png` を 16x16 で描き、3x3 に敷いて継ぎ目を確認する。
   `deno task check-palette` を通す
2. `static/catalog/base.json` の `cells` に記号を追加する (`canEnter`, 必要なら
   `noise` / `flip` / `variants` / `casts` / `slippery` / `water` / `conveyor` /
   `diggable`)
3. `tools/generate_preview_zoo.ts` の `CELLS` と `game/preview.ts` の `NOTES`
   に加える
4. 生成スクリプトで使う場所を決める (どの階のどの部屋か)
