# アイテムの使い分け (道具)

拾ったアイテムを「置く」ことで、プレイヤー以外のものを動かす仕組み。
レベルデザイン原則 1「プレイヤーは押すのではなく仕込む」
(docs/design-principles.md) をアイテムでも成り立たせる。

## 操作

- **道具を選ぶ**: X キー、または画面の下の PUT ボタン (`-` りんご 魚 種)。 X
  は「なし → りんご → 魚 → 種 → なし」の順に回る。選ぶと `PUT: APPLE (5)`
  のように手持ちの数が出る。
- **置く**: スペース (タッチは画面のタップ)。目の前のマスに置く。
  - 掘れる床の上では、置く前に掘るのが先。
  - 目の前が水なら置かずに釣りをする (水には何も置けない)。
  - 道具が「なし」のときは今まで通り (掘る、種を植える、釣り、ジャンプ)。
- **拾い直す**: 置いたりんごや魚は、上を歩けばまた拾える。食べられたら戻らない。

## 道具

| 道具   | 置くと                                                                | 役割       |
| ------ | --------------------------------------------------------------------- | ---------- |
| りんご | チェイサー (chaser) が 8 マス以内なら寄ってきて食べ、6 秒その場で座る | 引き寄せる |
| 魚     | 猫 (cat, fox) が 8 マス以内なら寄ってきて食べ、20 秒その場で眠る      | 止める     |
| 種     | 苗木 (sapling) を植える。マスを塞ぐ。育つとりんごの木になる           | 塞ぐ       |

- チェイサーは地面のりんごをプレイヤーより優先する (プレイヤーのりんごを
  盗みに来ない)。猫は魚に向かう間と眠っている間、プレイヤーから逃げない。
- チェイサーは魚を、猫はりんごを無視する。餌を間違えると何も起きない。
- 植えたばかりの苗木 (育つ前) は、押すと抜けて種が手持ちに戻る
  (氷の上で滑ってぶつかったときは抜けない: そこでは止め具になる)。
- 魚はついてくる 1 匹を置く。釣りで増やせる。

## 部屋を作るとき

- **ドアと乗り板 (plate) の距離で使い分けを問う。** ドアは誰かが板に乗って
  いる間だけ開く。板からドアまでがプレイヤー 1 人では間に合わない距離なら、
  板に誰かを乗せる必要がある。りんご (6 秒) で足りる距離か、魚 (20 秒) が
  要る距離か。
- **餌を部屋の中に置きっぱなしにしない。** 地面の餌は動物がすぐ食べてしまう。
  補充用の餌は動物から 9 マス以上離すか、部屋の外に置く。
- **失敗を安く (原則 7)。** 魚は池で釣れるようにする。種は苗木を抜けば戻る。
  岩が転がりすぎたら、部屋を離れて戻ると元の位置に戻る。

## 試せる部屋: BAIT (デバッグマップ)

デバッグマップ (block_10000.-10000) の入口にある「TO THE BAIT ROOMS」の
ポータルから行ける。入口の列に、りんご・種・魚と釣り用の池がある。

| 部屋 | 道具     | 仕掛け                                                                         |
| ---- | -------- | ------------------------------------------------------------------------------ |
| A    | りんご   | 板にりんごを置くと、チェイサーが食べて板に座る。その間にドアを抜ける           |
| B    | 魚       | 板に魚を置くと、猫が食べて板の上で眠る                                         |
| C    | 種       | 岩は板を通りすぎて壁まで転がる。板のすぐ先に苗木を植えると、岩が板の上で止まる |
| D    | 使い分け | 2 枚の板と 2 枚のドア。チェイサーにはりんご、猫には魚。長く眠る猫を先に        |
